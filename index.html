مشاريب وحلويات البار

• طبقة كيك - طبقة بيستاشيو بشعر الكنافة - مغطى بالنوتيلا والبستاشيو.

• قطعة كيك محشوة شوكلاتة بلجيكي - مغطاه بالنوتيلا - بولا آيس كريم فانيلا.

• قطعة كيك محشوة شوكلاتة بلجيكي - مغطاه بطبقة نوتيلا - مكسرات فاخرة مطحونة.

• طبقة شعر كنافة - خليط قشطة مع نوتيلا - مغطاه بطبقة نوتيلا - مكسرات فاخرة مطحونة.

• قطعة كيك مسقى بالشوكو الساخن - مغطى بالنوتيلا - بولا ايس كريم فانيلا.

• سيروب نكهة - صودا - ثلج.

• عجينة كريب - شعر كنافة مخفوق بالبستاشيو - مغطى بالنوتيلا من الخارج.

• ثلج - شوكو - حليب.

• ثلج - اسبرسو - حليب - سيروب شوكلت.

• ثلج - نسكافية - حليب - سكر حسب الطلب.

• افوكادو - موز - حليب - مكسرات - عسل.

• العصير الطبيعي المتوفر لكل موسم [فراولة-مانجا-جوافة] حسب المتوفر.

• عجينة كريب - نوتيلا أو لوتس أو مكس.

• عجينة وافل - طولية الشكل - نوتيلا أو مكس حسب الطلب.

• عجينة ميني - شكل دائري صغير - سوسير نوتيلا - سوسير لوتس.

• عجينة مخبوزة على شكل سمك - سوسير نوتيلا - سوسير لوتس.

قسم الكيك

• كريمة نوتيلا مع طبقات كيك ناعم.

• كيك مافينز محشو بالنوتيلا مغطى بالنوتيلا.

• كيك تركي مسقى بالحليب المكثف مغطى بنكهات / بلوبيري / شكولاته / كراميل / فراولة.

• كيك مافينز محشو بالنوتيلا مغطى بنكهات / بلوبيري / شكولاته / كراميل / فراولة.

• كيك مافينز محشو بالنوتيلا مغطى بنكهات النوتيلا / لوتس / بستاشيو.

• آيس كريم حسب الطعم المطلوب (فانيلا / فراولة / نوتيلا ) + حليب مع اضافة النكهة المطلوبة / لوتس / بستاشيو / نوتيلا.

• كريمة لوتس مع طبقات بسكويت لوتس ناعم.

• طبقة بسكويت ناعم + طبقة كريمة ومغطى بلوبيري.

• طبقة كيك ناعم + طبقة كريمة ومغطى بنكهات لوتس / شوكلاته / نوتيلا / مانجا / فراولة.

السندوتشات الغربية

ملاحظة هامة: جميع وجبات قسم الغربي يضاف معها صوص بيكانتي + مخللات + شيبس.

• خبزة برجر (فينو) - صوص بيكانتي - خس - شرائح بصل - جبنة برجر - مخلل خيار - بندورة - صدر دجاج كرسبي مقلي.

• خبزة برجر (فينو) - بيكانتي - خس - شرائح بصل - بندورة - قطعة لحم عجل مفروم مشوي - جبنة برجر.

• خبزة برجر - بيكانتي - خس - شرائح بصل - مخلل خيار - بندورة - قطعتين لحم مشوي - جبنة برجر.

• خبزة برجر - خس - بيكانتي - مخلل خيار - قطعة دجاج مفروم - جبنة برجر.

• فينو باجيت - شرائح صدر دجاج - فلفل حلو - مشروم - زيتون اسود - بصل - مطبوخ بالكاتشب - جبنة موزريلا.

• صاج - شرائح صدر دجاج - فلفل حلو - مشروم - زيتون اسود - bصل - مطبوخ بالكاتشب - جبنة موزريلا - مغطاه بالبقسماط.

• فينو باجيت - قطع صدر دجاج - فلفل اخضر - فلفل حلو - ثوم - بقدونس ناعم - صوص باربيكيو - بندورة - جبنة موزريلا على الوجه مع قطع فلفل اخضر.

• باجيت - قطعة صدر بالبقسماط - خس - بيكانتي - مخلل خيار.

• تفاصيل س/ الزينجر المعتادة وبحجم مضاعف ×2 دجاج كرسبي مقلي.

• قطع دجاج كرسبي مقلي + بطاطا (شيبس) في الأسفل + صوص رانش + صوص باربيكيو + فلفل هالبينو حار.

• شرائح بندورة + خس + سيخ قطع فخد دجاج مشوي + خبزة فينو.

• صاج عراقي + صدر دجاج مشوي + صوص بيكانتي + مخلل خيار + بندورة + خس + جبنة.

القسم الإيطالي

ملاحظة هامة: جميع وجبات قسم الإيطالي يضاف معها صوص رانش + مخللات.

• عجينة ايطالية - قطع صدر دجاج - جبنة موزريلا - زيتون اسود - صوص رانش - رشة شطة + يقدم مع شيبس.

• فلفل حلو - بصل - ذرة - زيتون اسود - مشروم - صوص رانش - جبنة موزريلا.

• عجينة ايطالية - صلصة ايطالية - جبنة موزريلا - فلفل حلو - مشروم - زيتون اسود - ذرة.

• عجينة ايطالية - صلصة ايطالية - جبنة موزريلا - زيتون اسود - قطع صدر دجاج - شطة.

• عجينة ايطالية - صلصة ايطالية - جبنة موزريلا - قطع مرتديلا سلامي.

• عجينة ايطالية - صلصة ايطالية - جبنة موزريلا - قطع مرتديلا سلامي - شرائح فلفل أصفر حار.

• عجينة ايطالية مستطيلة - قطع صدر دجاج - جرادة خضرا - فلفل حلو - بصل - مشروم مطبوخ بالوايت صوص- جبنة - زيتون اسود + يقدم مع شيبس.

• بيتزا سادة من العجينة والصلصة الإيطالية والجبنة فقط بدون أي إضافات.

• عجينة ايطالية - صلصة - موزريلا - تونة - زيتون اسود.

• مواصفات اساس البيتزا الإيطالية بالكامل - يضاف على الوجه قطع أناناس شهية.

• ذرة حلوة + جبنة موزريلا غنية + صلصة إيطالية مميزة.

• شرائح زيتون اسود وأخضر + جبنة موزريلا + صلصة إيطالية.

الشاورما

ملاحظة هامة: جميع وجبات قسم الشاورما يضاف معها طحينة + مخللات.

• صاج - شاورما - طحينة - محمصة على التوست ويضاف لها شيبس جانبي.

• صاج - شاورما - جبنة موزريلا - زيتون اسود - محمصة ومقرمشة ويضاف لها شيبس.

• خبزة برجر كبيرة - بيكانتي - شاورما - جبنة - زيتون اسود - في الفرن - محمصة ويضاف لها شيبس.

• خبزة فينو بيضاوية الشكل - بيكانتي - شاورما - جبنة - طحينة - زيتون اسود - محمصة على التوست ويضاف لها شيبس.

• صاج - شاورما - تقطع لدوائر متناسقة - جبنة موزريلا ذائبة ويضاف لها شيبس.

• بيكانتي - شيبس - شاورما - جبنة - 2 فراشيح صاج عراقي فاخر.

• وجبة شاورما محددة بوزن صافي 140 غرام من اللحم المتبل.

• وجبة دبل من اللحم بوزن يتراوح بين 170 إلى 180 غرام.

• صحن شاورما بوزن صافي يبلغ 250 غرام.
